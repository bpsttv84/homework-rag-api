Збережіть PNG/JPEG у цю теку з іменами нижче. Далі — які команди виконати перед скріном.

Спочатку задай базовий URL (локально або Fly):

  $BASE = "http://127.0.0.1:8080"
  або
  $BASE = "https://ТВІЙ-ДОДАТОК.fly.dev"

Сервер має бути запущений (uvicorn). Для Fly — після deploy і після POST /index/rebuild.

02-chat-stream-done.png
────────────────────────────────────────────────────────────
Варіант A — скрипт (підстав свій URL):
  $env:CHAT_API_URL = $BASE
  .\scripts\example-chat-stream.ps1

Варіант B — один рядок curl (заміни хост на свій, якщо не 8080):
  curl.exe --% -N -H "X-API-Key: sk-demo-free-rag" -H "Content-Type: application/json" -d "{\"message\":\"What is a backing service in the twelve-factor app?\"}" http://127.0.0.1:8080/chat/stream

Скрін: низ виводу з рядком data: де є \"type\":\"done\" та \"sources\".

────────────────────────────────────────────────────────────
06-429-retry-after.png  (опційно)
────────────────────────────────────────────────────────────
Треба перевищити token bucket (багато запитів або дуже «важкі» відповіді).
Приклад — багато коротких запитів підряд:
  1..40 | ForEach-Object {
    curl.exe -s -o NUL -w "%{http_code}`n" -H "X-API-Key: sk-demo-free-rag" -H "Content-Type: application/json" --data-raw "{\"message\":\"x$_\"}" "$BASE/chat/stream"
  }

Або з заголовками:
  curl.exe -v -N -H "X-API-Key: sk-demo-free-rag" ...
Поки не зʼявиться HTTP/1.1 429 і заголовок Retry-After.

Скрін: фрагмент з 429 і Retry-After.
